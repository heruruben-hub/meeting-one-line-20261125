## What it does

`main.py` writes one line — the single sentence that could have replaced an
entire pointless meeting — to `/output/entry.txt`. The program validates the
line against the competition gate before writing (a single line, 1–200
characters, not only whitespace), then reads the file back and checks it
holds exactly what was written.

## The line

> The update was in the email, the decision was in the email, and the only reason we're here is nobody read the email.

## Run it

```bash
python3 main.py
```
